Super Assistant is one AI agent for your daily work. It puts your tasks, tools and requests in one place. You state your goal. The assistant works out the steps and the tools that it needs.

## Key ideas

- **AI agent.** A program that uses an AI model to finish tasks. It can call tools and take many steps.
- **Aggregator.** A ready-made set of tools for one job. For example, a set of tools for a weekly report.
- **Token.** A small piece of text that a model reads or writes. Models count their work in tokens.

## How it works

1. You tell Super Assistant what you want to do.
2. The Goal Reader understands the goal. It sends each request to the most useful tool, service or aggregator.
3. Tool Coordination connects many tools to finish the work. This saves you from switching between many apps.
4. Token Strategy uses the context with care. The assistant keeps its focus and wastes fewer tokens.
5. Pavii checks each request. The privacy gate removes personal data and secrets before a model sees your request.

## What it helps with

- Hard tasks that need many steps across connected services.
- Daily work, your tools and agent actions in one assistant.
- Repeated workflows, with aggregators that do the same job each time.

## Who it is for

Super Assistant is for people, creators and businesses. It suits anyone who wants one AI workspace for tasks, tools, automation and paid workflows.
