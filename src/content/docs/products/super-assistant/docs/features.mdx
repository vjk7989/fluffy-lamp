Super Assistant combines several parts. Each part below has one job.

## Task Hub

The Task Hub holds your daily work, your tools and the actions of your agents. You see it all in one assistant. You do not need to switch between separate apps.

## Goal Reader

The Goal Reader reads what you want to achieve. It sends each request to the most useful tool, service or aggregator. You do not manage each step yourself.

## Tool coordination

Tool coordination connects many tools to finish one piece of work. Many tasks usually need several separate apps. The assistant runs these steps in order for you.

## Token strategy

The token strategy uses the context with care. The assistant keeps only the information it needs for the task. This keeps the assistant focused, and it still gives good answers.

## Aggregator marketplace

The marketplace holds aggregators from creators, teams and businesses. An aggregator is a set of tools that does one repeated workflow. You can use a ready-made aggregator instead of building your own.

## Creator income

Creators can publish an aggregator that other users find useful. Creators earn when people use it. Other users get more work done with the tools that the creator shared.

## Privacy by Pavii

The Pavii privacy gate removes personal data and secrets before a model sees your request. The model works with the task. Your private details stay out of the prompt.
