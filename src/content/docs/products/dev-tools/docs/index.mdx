HyperOx is a desktop app for running coding agents. Version 0.1.33 is in early
access. Enterprise version coming soon.

Install it with the [installation guide](/products/dev-tools/docs/getting-started/installation/).

## What is in 0.1.33

- Run coding agents (Claude Code, Codex, OpenCode, Gemini CLI, plus your own) in tabs and split panes, grouped into spaces per project or machine.
- An agents panel shows each agent's state (working, done or idle) and lets you pin agents.
- Ctrl+Shift+1 to 9 starts an agent in a new tab: 1 Claude Code, 2 Codex, 3 OpenCode, 4 Gemini CLI, then your own. It works on every keyboard layout. Add your own agents and CLI tools in Settings > Agents.
- Files, Changes (git), To-do and Sessions panels sit next to your terminals. Files that are not text open in their default app.
- Remote machines: add a machine and run agents there. The sidebar groups spaces by machine.
- Activity graph in Settings > Profile: your agent activity over the last year on this computer. It is kept privately on your computer.
- Themes: darkmatter (the default dark theme), Sodium, Voltage and Phosphor. HyperOx follows light and dark.
- Mods: the interface is scriptable with JavaScript mods.
- Signed releases (every file has a minisig signature) and in-app updates.
- Sign in with Google for account features. Profile lists Token saving, Observability engine, Blockchain security for PII masking, and Phone and Telegram pairing (through Remote).
