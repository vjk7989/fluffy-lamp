HyperOx is a control tower for your coding agents. Claude Code, Codex, OpenCode, Gemini CLI or your own each run in their own terminal, and HyperOx shows you which are working, which are done and which are waiting for you.

:::note[Beta and invite-only]
HyperOx is in beta, so not every feature described in these docs is in the current early-access app (0.1.33). The complete application is invite-only: we email a few selected users an invitation to try it. Enterprise version coming soon.
:::

## Where to start

- **Getting started.** [Install](/products/dev-tools/docs/getting-started/installation/) the app, then take your [first launch](/products/dev-tools/docs/getting-started/first-launch/).
- **Using HyperOx.** [Spaces, tabs and panes](/products/dev-tools/docs/using-hyperox/spaces-tabs-panes/), [running agents](/products/dev-tools/docs/using-hyperox/running-agents/), panels, remote machines, themes and updates.
- **How it works.** What the account features do: [token saving](/products/dev-tools/docs/how-it-works/token-saving/), [privacy and blockchain-backed masking](/products/dev-tools/docs/how-it-works/privacy-and-masking/) and [observability](/products/dev-tools/docs/how-it-works/observability/).
- **Help.** [Troubleshooting](/products/dev-tools/docs/help/troubleshooting/) and [privacy and data](/products/dev-tools/docs/help/privacy-and-data/).

## In the app today

- Agents in tabs and split panes, grouped into spaces per project or machine.
- An agents panel with each agent's state, and shortcuts Ctrl+Shift+1 to 9 to start them.
- Files, Changes (git), To-do and Sessions panels.
- Remote machines, themes, mods, signed releases and in-app updates.
