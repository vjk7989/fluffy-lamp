## Themes

Pick a theme in Settings. darkmatter is the default dark theme. Sodium, Voltage, Phosphor and others are included. HyperOx follows light and dark.

## Layouts

Choose how panels and terminals are arranged. Change it any time; your spaces stay as they are.

## Mods

The interface itself is built from JavaScript mods, which you can change. Like a workshop with movable walls, you can reshape the parts you use most.
