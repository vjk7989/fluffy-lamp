HyperOx does not replace your coding agent. It gives each one a place to work, like a control tower that watches every runway.

## Start an agent

Press Ctrl+Shift and a number to start an agent in a new tab. It works on every keyboard layout.

| Keys | Agent |
| ---- | ----- |
| Ctrl+Shift+1 | Claude Code |
| Ctrl+Shift+2 | Codex |
| Ctrl+Shift+3 | OpenCode |
| Ctrl+Shift+4 | Gemini CLI |
| Ctrl+Shift+5 to 9 | Your own |

The + menu and the command palette (Ctrl+Shift+P) list the same agents.

## Add your own

Open Settings > Agents to add, edit or remove agents and CLI tools. Give each a name and the command that starts it. It then gets a shortcut, from 5 upward, and a place in the menus.

The agent's CLI must be installed on the machine. If it is not, HyperOx shows a message instead of opening a dead tab.

## Agents panel

The Agents panel in the sidebar shows every agent and its state: working, done or idle. Pin the ones you want to keep in view, so you can glance over instead of hunting through tabs.
