Think of HyperOx as an office building. Each space is a floor, each tab is a room, and each pane is a desk.

## Spaces

A space holds the work for one project or one machine. Keep a space per project and switching context is a single click. The sidebar lists your spaces, grouped by machine once you add remote ones.

## Tabs

A space holds tabs. A tab might be one agent, one test run or one dev server. Starting an agent with a shortcut opens it in a new tab.

## Panes

Split a tab into panes to see several terminals at once: an agent on the left, your tests on the right. Each pane is a normal terminal, so anything you can run in a shell runs here.

## Command palette

Press Ctrl+Shift+P to search every action: new space, new tab, start an agent, change theme.
