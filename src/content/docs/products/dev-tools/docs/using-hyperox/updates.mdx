## In-app updates

HyperOx updates itself from inside the app. When a new version is ready, it offers to install it.

## Signed releases

Every release file ships with a `.minisig` signature, like a wax seal on a letter. The installers check the seal before they unpack anything. A file that was changed on the way to you fails the check and is not installed.

For install steps, see [Installation](/products/dev-tools/docs/getting-started/installation/).
