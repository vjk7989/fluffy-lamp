## Remote machines

Add a remote machine and run agents there, using the same tabs and panes as at home. It is useful for a stronger server or a project that lives elsewhere. The sidebar groups your spaces by machine, so you always know where an agent is running.

## Phone and Telegram

Pair your phone or Telegram to follow your agents and answer them when they ask a question. Think of it as a pager: you step away from the desk, and the agent can still reach you.

Pairing needs you to be signed in. See [First launch](/products/dev-tools/docs/getting-started/first-launch/).
