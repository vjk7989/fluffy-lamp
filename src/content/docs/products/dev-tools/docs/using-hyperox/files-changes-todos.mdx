Panels give you the workbench around the agent, so you rarely leave the window.

## Files

Browse the project tree. Files that are not text, such as images or PDFs, open in their default app. In a terminal, Ctrl+click a file name in the output to open it at its line.

## Changes

See what the agent changed as a git diff, then commit from the same panel. It is the quickest way to review before you accept work.

## To-do

Keep a short list beside the terminal for what you want next, or what an agent left undone.

## Sessions

Sessions lists your agent sessions, so you can find one again.
