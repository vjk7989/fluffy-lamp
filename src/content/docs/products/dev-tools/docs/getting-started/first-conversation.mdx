With an assistant picked and a model connected, type a message and press
Enter. The agent streams its reply, shows the tools it uses, and asks for
permission when an action needs your approval.

## Attach files and folders

Use the **+** button in the composer — or type `/open` — to attach files or
pick a project folder. Agents work inside the workspace you give them, so
attaching the right folder is how you point a coding agent at your project.

## The "/" command menu

Type `/` at the start of the composer to open the command menu. It combines
three sources into one list:

1. **Your agent's own commands** — whatever the connected CLI advertises. For
   OpenCode that includes commands like `/init` and `/review`. These stay
   available between turns, not just while the agent is mid-response.
2. **App commands** — `/new` starts a new conversation, `/agents` takes you to
   assistant selection, `/copy` copies the last reply.
3. **Your skills** — skills enabled on the current assistant appear as
   commands. Picking one genuinely loads the skill for that message, so the
   agent has its full instructions — it is not just text insertion.

Keep typing after the `/` to filter the list; arrow keys and Enter select.

## Switching mid-flight

- `/agents` — change assistant.
- The model selector in the header — change the model for this conversation.
- The permission selector — raise or lower agent autonomy per conversation.
