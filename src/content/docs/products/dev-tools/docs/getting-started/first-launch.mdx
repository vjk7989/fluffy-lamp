The first time HyperOx opens, a welcome screen offers two paths. Both lead to the same app.

## Sign in, or skip

Signing in opens your browser at pavii.tech. Choose Google, GitHub or email, and you come back signed in. It switches on the account features: Token saving, the Observability engine and Blockchain security for PII masking. These belong to the complete application, so what you see depends on your access.

:::note[Beta and invite-only]
HyperOx is in beta, so not every feature described here is in the current early-access app. The complete application is invite-only: we email a few selected users an invitation to try it.
:::

Skip sign-in and everything else keeps working: spaces, agents, panels, themes and remote machines.

## Your first space

A space holds the work for one project or machine. Create one, then point it at your project folder. It opens with a single tab and a terminal.

## Your first agent

Press Ctrl+Shift+1 to start Claude Code in a new tab. If the agent's CLI is not installed yet, HyperOx tells you with a short message. Install it, then try again.

Other keys start Codex (2), OpenCode (3) and Gemini CLI (4). More in [Running agents](/products/dev-tools/docs/using-hyperox/running-agents/).
