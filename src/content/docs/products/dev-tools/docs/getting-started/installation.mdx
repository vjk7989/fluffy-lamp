## Planned design

Pavii.Ai is planned to ship as one installer for each platform: Windows,
macOS and Linux. The plan includes these parts:

- **The desktop app** — the interface that you talk to.
- **Pavii Engine** — a local engine that manages conversations, agents and
  your data. It runs on your machine. Your data directory stays local.
- **OpenCode CLI** — the default coding agent. It is planned to be ready in
  your first session. If you have your own OpenCode, Pavii.Ai uses your copy.
