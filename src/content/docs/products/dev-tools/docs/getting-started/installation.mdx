HyperOx 0.1.33 is in early access. The installers check each release's
signature, then install the app and HyperOx core.

## Requirements

- Windows 10/11 x64
- macOS on Apple Silicon (Intel Macs are not supported)
- Linux x86_64 or aarch64

## Download

Get the archive for your system from the
[releases page](https://github.com/buckleson/h0x-ADE-Releases/releases/latest).
There is no `.exe` or `.dmg` installer. Each archive has a `.minisig` signature
next to it.

| Platform | File |
| -------- | ---- |
| Windows x86_64 | `h0x-ade-windows-x86_64.tar.gz` |
| macOS Apple Silicon | `h0x-ade-macos-aarch64.tar.gz` |
| Linux x86_64 | `h0x-ade-linux-x86_64.tar.gz` |
| Linux aarch64 | `h0x-ade-linux-aarch64.tar.gz` |

## Install with a command

The installers are signed scripts. They verify the `.minisig` signature before
they unpack anything.

### macOS and Linux

```sh
curl -fsSL https://github.com/vjk7989/h0x-ADE-app/releases/latest/download/install.sh | sh
```

On macOS the app goes to `~/Applications/HyperOx.app`. On Linux the installer
adds a launcher entry.

### Windows (PowerShell)

```powershell
powershell -c "irm https://github.com/vjk7989/h0x-ADE-app/releases/latest/download/install.ps1 | iex"
```

HyperOx installs to `%LOCALAPPDATA%\Programs\h0x-ade` and is added to your
PATH.

### Windows (curl.exe)

Download the installer, then run it:

```powershell
curl.exe -fsSLo "$env:TEMP\hyperox-install.ps1" https://github.com/vjk7989/h0x-ADE-app/releases/latest/download/install.ps1
powershell -ExecutionPolicy Bypass -File "$env:TEMP\hyperox-install.ps1"
```

## Self-sign on macOS

The installer already signs the app. Run this if you downloaded the tarball by
hand, or if macOS says the app is damaged:

```sh
xattr -dr com.apple.quarantine ~/Applications/HyperOx.app && codesign --force --deep --sign - ~/Applications/HyperOx.app && open ~/Applications/HyperOx.app
```

## Updates

HyperOx updates itself from inside the app. Releases are signed.
