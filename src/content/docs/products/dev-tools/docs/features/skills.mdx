Skills are reusable instruction packs — coding workflows, review checklists,
writing styles, token optimization — that teach an agent how you want a job
done.

## The skills library

Open **Settings → Skills** to browse the built-in library, organized by
category with official skills listed first. Alongside the curated set you can
add your own custom skills and manage everything in one hub.

## Enabling skills

Skills are enabled per assistant, so each assistant carries exactly the
toolkit you give it. Auto-inject skills apply to every message automatically;
the rest wait until you invoke them.

## Using a skill in conversation

Type `/` in the composer — your assistant's enabled skills appear as commands.
Picking one loads the skill for that message, so the agent receives its full
instructions, not just the skill's name as text.

## Notable built-ins

- **Token Optimizer** — focused on trimming prompt cost.
- Coding workflow packs — test-driven development, debugging, code review,
  and more.
