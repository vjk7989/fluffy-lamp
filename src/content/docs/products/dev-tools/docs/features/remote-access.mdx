Your workspace does not have to stay on one screen.

## WebUI

The desktop app includes a built-in web interface. Enable it in
**Settings → WebUI** and open your workspace from a phone or another computer
on your network — same conversations, same assistants.

Access is protected by its own login, separate from the desktop app's Pavii
account sign-in. An initial admin password is generated the first time it
runs, and can be reset from the settings page.

## pavii-web

For running the workspace on a server, `pavii-web` is a headless distribution:
a single executable plus the engine, installed with one command and serving
the same web interface without the desktop app.

## Good to know

- The agents still run on the machine hosting the workspace — remote access
  is a window into it, not a separate copy.
- Combined with [channels](/products/dev-tools/docs/features/channels/), you
  can reach the same assistant from chat apps as well as the browser.
