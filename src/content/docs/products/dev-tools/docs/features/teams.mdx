For work too large for one conversation, Pavii.Ai can run a team of agents.

## How teams work

- **A leader agent** receives your goal, breaks it into tasks, and dispatches
  them to teammates.
- **Teammate agents** work their tasks and report back; the leader collects
  results and coordinates the next steps.
- You watch the team's message flow in one place instead of juggling parallel
  conversations yourself.

## When to reach for a team

- Work that naturally splits — several files to review, several questions to
  research, several components to change.
- Long jobs where a single conversation's context would fill up carrying
  everything alone.

## Setting one up

Create a team from the conversation surface, choose which assistants join it,
and give the leader your goal. Permission settings apply to team members the
same way they apply to a single agent.
