Scheduled tasks let your agents work without you pressing send.

## What you can schedule

- Recurring jobs — a daily summary, a periodic check, a report built on a
  schedule.
- One-off reminders and delayed tasks.

## Creating a scheduled task

1. Open the **Scheduled** page from the sidebar.
2. Create a task: what the agent should do, which assistant runs it, and when
   (one-time or a repeating schedule).
3. The task runs on its timer; results land in your conversation history.

## Good to know

- Tasks execute on the machine running your workspace — the desktop app or a
  `pavii-web` server must be running at the scheduled time.
- Combined with [channels](/products/dev-tools/docs/features/channels/), a
  scheduled task's outcome can reach you in Telegram, Slack, or Discord.
