An agent can run for minutes and touch dozens of files. Observability is the flight recorder: when something goes wrong, or very right, you can replay it.

## Logs

What each agent ran, and the output it got. The plain record.

## Traces

The step-by-step path of one session: prompts, tool calls, file changes and timings. Where logs list events, a trace connects them into a story.

## Evals

Repeatable checks that score an agent's results against what you expected. Run them again after a change to see whether things got better or worse.

## Cost and tokens

Spend per agent and per session, so you know what a task cost. Pair it with [Token saving](/products/dev-tools/docs/how-it-works/token-saving/).

## Turning it on

The Observability engine is part of the complete application and switches on when you sign in. On your own computer today, the activity graph in Settings > Profile shows minutes, sessions and tokens per day for the last year, stored only on that computer.
