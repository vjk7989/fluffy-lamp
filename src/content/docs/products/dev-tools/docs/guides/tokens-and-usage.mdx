AI work costs tokens. Pavii.Ai makes the spend visible and gives you tools to
keep it down.

## Usage tracking

Your **profile page** shows usage statistics and an activity heatmap, powered
by a local per-day usage ledger — the numbers live on your machine, not on a
server.

## Context visibility

The composer shows how full the current conversation's context is. When a long
session approaches the limit, you can start a fresh conversation (`/new`) or
let agent commands like OpenCode's `/init` re-ground the session instead of
carrying stale history.

## Trimming cost

- **Token Optimizer** — a bundled skill focused on reducing prompt cost;
  enable it on an assistant and invoke it from the `/` menu.
- **Skills discipline** — skills load only when you pick them, and a skill
  already loaded in the conversation is never re-sent, so its cost is paid
  once, not per message.
- **Free providers** — for experiments, route conversations to a free model
  option in the picker and keep the paid key for real work.
